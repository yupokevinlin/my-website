# Translation glossary

How the site's recurring terms are translated, so every file uses the same
words. Translators and anyone editing a translation: follow this, and add
to it when you settle a new term.

General rules for every language:

- Keep the shape of the file (keys, array order and lengths); tests compare it with the English.
- Keep functions as functions with the same parameters, and every `${...}` placeholder they use.
- Never translate: names of companies, products, tools and people; formulas; units that are symbols (M, ρ, °, K, c, γ, EV, ×); key letters (F, P, H) and "4K", "WebGL 2".
- In the guide, a subscript is written `r_s` or `r_{s}`. Keep that form exactly.
- Short labels (diagram labels, buttons, tabs, settings) stay about as short as the English: they sit in fixed spaces.
